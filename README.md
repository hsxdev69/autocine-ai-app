# 🎬 AutoCine AI Studio (Android App + CapCut-Style Editor)

An autonomous AI Video Creation Engine & Multi-track Timeline Editor built with **Flutter**, **Edge-TTS**, and **GitHub Actions CI/CD**.

---

## ✨ Features

- 🧠 **Autonomous AI Topic Research:** Enter any topic, and the engine plans scenes, visual cues, and narratives.
- ✂️ **CapCut-Style Multi-Track Timeline:**
  - Track 1: Visuals & B-roll (Trim, Split, Swap Scene Visuals)
  - Track 2: Voiceover Audio (Per-scene text edit & instant re-synthesis)
  - Track 3: BGM & Sound Effects (Volume slider & automatic ducking)
  - Track 4: Dynamic Word-by-Word Bouncing Captions
- 📱 **Dual Format Modes:** 9:16 Vertical (Shorts / Reels) & 16:9 Landscape (YouTube Long-form).
- 🎙️ **Multi-Voice Studio:** Supports `Madhur (Tuned Deep)`, `Viraj (ElevenLabs)`, and `Salman (Velvety)`.
- ☁️ **Zero-Load Cloud Build:** Automatic APK compilation via GitHub Actions!

---

## 🚀 How to Build APK with GitHub Actions

1. Push this repository to GitHub (`main` branch).
2. Go to the **Actions** tab on your GitHub repository.
3. The **Build Android APK** workflow will automatically run and compile the APK on GitHub's servers (without using any local CPU/RAM).
4. Download the `AutoCine-Release-APK` artifact or download from the **Releases** page directly to your phone and install!
